喵想奇记 操作说明

适用版本：家用版（喵想奇记.exe，2026-10 版） 阅读方式：第一次用，请按顺序看第 1～4 章；想马上干活，直接跳到第 3 章「五分钟上手」。

1. 这个软件是干什么的

把你在电脑上重复做的一遍操作录下来，之后点一下就能原样重放；也可以让它在固定时间自动执行。

它能记录和重放的东西：

  • 鼠标移动、单击、双击、右键、滚轮
  • 键盘输入、组合键（Ctrl+S 这类）
  • 每个动作之间的停顿时间（所以回放节奏和你录的时候一样）

它多做了一件很多同类工具没有的事：认图点击。不是死记坐标，而是按你截的图在屏幕上找——找到就点，窗口挪了位置也照样找得到。适合操作后台系统、OA、收银端这类界面固定但位置会变的场景。

2. 安装与启动

2.1 没有安装过程

喵想奇记.exe 是单文件程序，放到哪个文件夹就在哪个文件夹运行，不用安装、不写注册表。

建议这样放：

D:\喵想奇记\
    喵想奇记.exe
    scripts\          ← 程序第一次运行会自动建，你的录制脚本都存这里
    screenshot_click\ ← 截图组数据（任务配置 + 截图文件），跟着文件夹走

⚠️ 别把 exe 放在桌面或回收站旁边。程序会在自己所在目录建 scripts、script_groups、mixed_groups、images 四个文件夹，桌面放一堆文件夹会很乱。

2.2 第一次打开可能遇到的两件事

现象原因怎么办
双击后没反应，或者快捷键按了不理人目标程序（如某些后台系统）是管理员权限运行的，普通权限的模拟按键会被系统拦住右键 喵想奇记.exe → 属性 → 兼容性 → 勾选 「以管理员身份运行此程序」
杀毒软件报毒 / 被删除这类"模拟键鼠"的程序容易被误判在杀毒软件里把 exe 加入信任 / 白名单

2.3 主界面长什么样

打开后窗口自动铺满全屏（最大化），整体是「顶部工具条 + 三个竖列 + 下方日志 + 底部执行控制」：

位置名称作用
顶部左搜索框 + 「搜索」脚本多了以后，输入名字筛选「可用脚本」列表
顶部右「截图高级设置」「组管理」「定时任务」「停止录制」「开始录制」+「字体：\_\_%」「检查更新」不常用的开关都收在这里，主界面只留高频操作
左列可用脚本你录过的所有脚本；脚本组、混合组也在这里以 ▶ [脚本组] 形式出现
中列第二种操作模式：截图顺序识别点击认图点击的配置区，独占一整列，任务多也看得下
右列执行队列待办清单，点「▶ 开始执行」就按这个顺序跑
下方执行日志彩色高亮的运行记录，出问题先看这里
底部进度条（带百分比与步数）+ 「▶ 开始执行」「■ 停止」「⏸ 暂停」「▶ 继续」+ 「速度倍数」「自动继续」执行控制

三列宽度会随窗口自动伸缩，窗口拉多大都不会留下空白区域。

字体大小（适配不同设备）：顶部右侧「字体：\_\_%」下拉框，可以在 70% ~ 200% 之间调整整个软件界面的字体大小——换了一台分辨率/DPI 不一样的电脑，觉得字太小或太大，选一个百分比立刻生效，并自动记住，下次打开还是这个大小；选回 100% 就是系统默认。软件界面、菜单、日志、弹窗里的文字都会跟着变。

在线版本更新：软件启动时会自动检查 GitHub 上有没有新版本（联网失败会静默跳过，不影响使用）。发现新版本会弹出提示框，展示新版本号和更新内容，你可以：

  • 点「立即更新」：软件自动下载新版（有进度条，直连失败会自动切换国内加速源），下载完自动替换并重启，重启后会弹出「✅ 已更新到 vX.X.X」窗口展示本次更新了什么；
  • 点「以后再说」：继续用当前版本，下次打开软件会再提醒。

也可以随时点顶栏「检查更新」手动检查（已是最新版会提示"当前已是最新版本"）。窗口标题栏会显示当前版本号（如 v1.1.0）。普通版和 Win7 版各自只下载对应的安装包，不会串版本。

右上角有一个 ? 图标，鼠标悬停会显示快捷键速查。

3. 五分钟上手：录第一个脚本

目标：让软件自动打开记事本、敲一句话。

第 1 步：开始录制

点左下角 「开始录制」（或按 Ctrl+Alt+F9），弹出「开始录制...」提示后，程序就开始记录你的一切键鼠动作了。

第 2 步：正常做一遍你要它做的事

比如：

  1. 按 Win+R，输入 notepad，回车
  2. 等记事本打开（正常等，别急着动）
  3. 打几个字

⚠️ 从点「开始录制」这一刻起，你所有的鼠标移动都会被记下来，包括无关的抖动。所以录制期间手别乱晃，也别去点别的窗口——不然回放时鼠标会跟着乱跑。

第 3 步：停止并保存

点 「停止录制」（或按 Ctrl+Alt+F10），弹出「请输入脚本名称：」，输入 打开记事本，确定。

左下角「可用脚本」里就多了一条 打开记事本，磁盘上对应 scripts\打开记事本.json。

第 4 步：回放

  1. 双击列表里的 打开记事本 → 弹出「重复次数」，填 1
  2. 点底部 「▶ 开始执行」

鼠标会自己动起来。想中途停下按 「■ 停止」 或 Ctrl+Alt+F12。

4. 界面逐个说清楚

4.1 「可用脚本」区的按钮

先单击选中一条，再点按钮。

按钮作用
搜索框 + 「搜索」按名称过滤列表
「重命名」改脚本名（同时改文件名，别的组里引用它的地方会失效，慎用）
「删除」删除脚本（会二次确认，删了就没了，脚本文件一并删除）
「新建脚本组」把多个脚本串成一条流水线
「新建混合组」建一个能同时装 脚本 / 脚本组 / 截图组 的复合流程
「组操作…」打开「脚本组 / 混合组管理」窗口，集中做编辑、入队、删除（见 4.5）

单击是选中，双击是加入队列（会问你重复次数）。

4.2 「执行队列」区的按钮

按钮作用
「添加选中脚本」把左侧选中的脚本加进队列；会依次问你重复次数和匹配阈值（阈值直接回车用默认 0.5 即可，当前版本不参与判断）
「截图组入队」把当前选中的截图组整组加进队列
「移除」移除选中项
「清空」全部清空，并重置执行状态

队列里的条目可以用鼠标拖动来调整顺序：按住一条往上/往下拖，松手即生效。

队列里可能出现这几种前缀，代表不同类型：

  • 脚本名 (x2) —— 普通录制脚本，重复 2 次
  • [脚本组] 组名 —— 一串脚本
  • [混合组] 组名 —— 脚本 + 脚本组 + 截图组混排
  • [截图组] 组名 —— 一整组认图任务
  • [截图任务] 名字 —— 单个认图任务

4.3 底部执行控制

控件说明
进度条按"总事件数"推进，右侧实时显示百分比与明细，如 40% (120/300)；截图流程显示 40% 4/10 步。含截图任务的流程在等图时会暂时停住，属正常
「▶ 开始执行」从队列第 1 项开始跑（Ctrl+Alt+F11）
「■ 停止」立即中止（Ctrl+Alt+F12）。停止后再开始是从头跑，进度条归零
「⏸ 暂停」暂停，记住当前位置（Ctrl+Alt+F7）
「▶ 继续」从暂停处接着跑（Ctrl+Alt+F8）
「速度倍数」1～10。1 = 原速，2 = 快一倍，10 = 十倍的快进
「自动继续」勾上后，队列跑完一项不停顿、直接下一项，直到全部结束
状态栏（左下）就绪 / 执行中 / 已暂停 / 执行完成

执行日志的彩色高亮（一眼看到关键操作）：

颜色代表
绿色加粗成功、完成、已启动
红色（浅红底）错误、失败、异常
橙色加粗警告、超时、跳过、防死机自动停止
紫色加粗定时任务、按键触发、截图流程、倒计时
蓝色执行脚本 / 任务步骤
灰色时间戳

日志最多保留 1500 行，超出后自动丢弃最旧的内容，长时间挂着也不会越用越卡。

「自动继续」不勾时的实际行为（容易误解，重点看）：

  • 队列里连续的普通脚本会自动一条接一条跑完，不会每条都停
  • 但遇到脚本组 / 混合组 / 截图组，跑完这一项就会停住等人，日志提示"队列已暂停，按 Ctrl+Alt+F11 继续"
  • 勾上「自动继续」= 全程无人值守

4.4 快捷键（全局生效，软件在后台也管用）

快捷键作用
Ctrl+Alt+F9开始 / 停止录制
Ctrl+Alt+F10停止录制并保存
Ctrl+Alt+F11开始执行 / 继续下一个
Ctrl+Alt+F12停止执行
Ctrl+Alt+F7暂停
Ctrl+Alt+F8继续
Ctrl+Alt+F1重新执行（从头再来一次）

4.5 「组管理」窗口

顶部工具条点 「组管理」（或左列「组操作…」）打开，专门管脚本组和混合组，避免主界面按钮堆成一片：

区块按钮作用
脚本组「新建脚本组」把多个脚本串成一条流水线
「编辑」修改选中的脚本组（增删脚本、调顺序）
「入队」把选中的脚本组加进右侧执行队列
「删除」删除整个组（组里的脚本不会删）
混合组「新建混合组」建一个能装 脚本 / 脚本组 / 截图组 的复合流程
「编辑」修改混合组
「入队」把选中的混合组加进执行队列
「删除」删除混合组

操作对象是左列「可用脚本」里当前选中的那一项，所以先选中再开这个窗口。

5. 录制脚本的实操建议

5.1 录制前

  • 关掉聊天弹窗、微信/QQ 消息提示、系统更新提示——它们会抢焦点，导致录进去的动作全乱
  • 把要操作的目标程序先打开好、登录好，录制范围只包住关键动作
  • 需要点得准的地方，录制时慢一点、稳一点

5.2 录制中

  • 鼠标少绕圈，尽量直线移动
  • 需要等待页面加载时，正常停一下再动；这段停顿会被如实记录，回放时也会等
  • 打错字不用慌，回放时也照样还原（包括按退格），只要最终结果是对的

5.3 录制后

  • 用「速度倍数」调快慢：录的时候慢，回放时用 2～3 倍往往刚好
  • 跑到一半点错位置，说明录制时有多余动作，建议重录，比手工改 JSON 快
  • 一个脚本只干一件事（比如"导出当月工资表"），需要串起来就用脚本组，别录成一大坨

5.4 脚本存在哪

  • 脚本：软件目录\scripts\脚本名.json
  • 脚本组：软件目录\script_groups\组名.json
  • 混合组：软件目录\mixed_groups\组名.json
  • 截图组（任务 + 截图文件）：软件目录\screenshot_click\tasks.json + 软件目录\screenshot_click\images\

换电脑或备份，把整个软件文件夹拷走即可，脚本和截图组都会一起带走。（旧版本把截图数据存在 %APPDATA%\MiaoXiangQiJi\，新版本首次运行会自动迁移到软件文件夹，原数据保留作备份）

6. 脚本组：把几个脚本串成流水线

适用：一件正事需要"开系统 → 导出 → 清理 → 另存"好几个脚本连起来做。

6.1 新建

  1. 点「新建脚本组」→ 窗口「创建脚本组」
  2. 填 脚本组名称
  3. 在 「执行前提醒内容（组级别）」 里写这次要注意什么（例如"请先确认已登录 OA"）。执行前会弹窗显示这段字
  4. 左边 「所有脚本（双击添加）」 里双击脚本，逐个加进右边
  5. 用「上移」「下移」「移除 ←」调整顺序
  6. 点「保存修改」

6.2 执行

选中该组 → 点「脚本组入队」→ 「▶ 开始执行」。

执行前会弹出 「执行脚本组前提醒 - 组名」，三个按钮：

  • 「我已确认，继续执行」 —— 开始跑
  • 「跳过此脚本」 —— 跳过
  • 「停止执行」 —— 中止

组内每个脚本跑完，默认会暂停等你按 Ctrl+Alt+F11 继续（方便你检查中间结果）。想一口气跑完，勾上底部的 「自动继续」。

7. 混合组：脚本、脚本组、截图组任意组合

脚本组里只能放脚本；混合组什么都能放。这是做复杂流程的主力。

7.1 新建

  1. 点「新建混合组」→ 窗口「新建混合组」
  2. 填 混合组名称、执行前提醒内容（组级别）
  3. 中间是 「步骤列表（从上到下执行）」，用下面几个按钮往里加：
    • 「添加脚本」
    • 「添加脚本组」
    • 「添加截图组」
    • 「添加截图任务」
  4. 双击某个步骤可以打开「步骤设置」，里面只有两项，但很好用：
    • 「执行后等待(秒)」 —— 这一步做完后等多久再进下一步（等页面加载、等文件生成）
    • 「执行完后自动继续（不暂停）」 —— 这一步单独设定是否要停
  5. 「上移」「下移」「移除步骤」调顺序，最后保存

7.2 什么时候该用混合组

  • 先跑脚本登录，再用认图点几个按钮（比死坐标稳）
  • 先认图等某个加载完成的标志出现，再执行导出脚本
  • 一串流程里有的步骤要停顿确认、有的要一路跑完

8. 认图点击：截图顺序识别

8.1 它解决什么问题

录制脚本记的是绝对坐标。屏幕分辨率变了、窗口挪了、缩放改了，回放就点歪。

认图点击是按图找位置：先截一张要点的那个小按钮的图，程序在屏幕上找这张图，找到就在它身上点。窗口挪到哪里都能找到。

8.2 准备截图（最容易做错的一步）

先用微信/QQ 的截图，或按 Win+Shift+S 截屏，把要点的那个按钮（或那行字）截下来，存成 .png 或 .jpg。

三个要点：

  • 只截目标本身，周围留一点点边即可。截太大 → 找得慢、容易误判；截太小 → 特征不够，认不出
  • 同一台电脑、同一缩放比例下截的图才认得出。别的电脑分辨率/缩放不同，要重新截
  • 截图里别有会变的内容（时间、数字、鼠标指针、动画）

8.3 添加一个认图任务

  1. 点「添加截图」→ 弹出文件选择框「选择用户截图」→ 选你刚存的那张图
  2. 打开 「添加截图操作」 窗口，上半部是你的截图预览：
    • 红色十字 = 基准点：在预览上点一下你要点的位置
    • 蓝色十字 = 最终操作点：等于"基准点 + X/Y 微调"。默认微调是 0，两个十字重合
    • 想点按钮之外的地方（比如按钮右侧的输入框），就调 「X 微调」「Y 微调」（正数向右/向下，负数向左/向上），蓝十会跟着移动，可以移到截图外面
  3. 下半部「操作设置」：
字段怎么填
识别后操作见下表 12 种可选
X 微调 / Y 微调一般 0；要偏离目标点时再调，范围 ±5000
匹配阈值默认 0.75。建议 0.70～0.90：越高越严格（一点不像就不认），越低越宽松（容易认错）。认不出→调低到 0.70；认错了→调高到 0.85
识别后等待点完停几秒再干下一步，等页面反应。默认 0
重复操作这个任务执行几次，默认 1
  1. 如果"识别后操作"选了 「键盘按键」 或 「输入文本」，下半部「键盘操作」区才起作用：
字段说明
按键组合如 enter、tab、esc、f5、ctrl+s、ctrl+v、alt+f4、ctrl+shift+esc；多个动作用逗号分隔，如 tab, enter、tab, tab, enter；组合键用 +
输入文本最多 300 字，支持中文；不会占用系统剪贴板
输入后按回车勾上则输完自动回车
  1. 选了 「滚轮下滚 / 滚轮上滚」 时，用 「滚动格数」 控制滚动幅度（1～50 格，1 格 ≈ 3 行文字）；滚动前鼠标会自动移到屏幕中央，保证滚的是页面。勾选 「未命中时自动加滚」 后，如果滚完这轮流程里始终没识别到目标，下一轮自动多滚 1 格（3→4→5…），一旦命中就恢复你设定的格数——适合"目标可能在下一两屏，但不确定隔多远"的翻页场景。
  2. 「命中目标」：累计成功执行 N 次后整个截图流程自动停止（0 = 不限制），见 8.8 末尾。
  3. 「点击后校验」：勾上后每次点击 1 秒后复查，目标还在原位说明点击没生效（比如被悬浮输入栏/弹窗遮挡）——本次不计入命中目标次数，该位置也不再重复点击。适合目标可能被遮挡的点击类任务（普通任务和条件分支都有此选项）。
  4. 点 「保存设置」

14 种「识别后操作」：

鼠标类（12 种）：左键单击、左键双击、右键单击、右键双击、中键单击、左键按下、左键释放、右键按下、右键释放、仅移动鼠标、滚轮下滚、滚轮上滚 键盘类（2 种）：键盘按键、输入文本

小技巧：左键按下 / 左键释放 用来做"拖拽"——一个任务按下、中间插入移动、下一个任务释放。

8.6 运行认图流程

有三种跑法：

  • 整组跑：选中「截图组」→ 「截图组入队」→ 「▶ 开始执行」；或直接点 「▶ 开始按顺序识别并点击」 立刻开始跑当前组
  • 单个跑：选中一个任务 → 「入队单个任务」
  • 按键触发跑：见 8.7，按一下键就让整组从头重跑
  • 停止：点 「■ 停止识别」

本组循环（每组独立）：开始按钮旁的「本组循环 __ 次」填几，就把当前选中的截图组的任务列表从头到尾跑几遍（进度条跨轮累计，日志里能看到"第 2/20 轮"）。循环次数按截图组各自保存——切换到别的组会显示那个组自己的次数，互不影响；数据随截图组一起保存，拷到别的电脑也带着。适合"每轮点一个赞、点完滚一屏"这类重复流程；填 1 就只跑一遍。循环可以填很大的值（如 999），再配合任务的「命中目标」（见 8.10）做到"点够 N 个就自动停"。

运行时中列下方会显示 状态（未开始 / 正在执行第几步 / 全部任务已完成 / 已停止），底部进度条同步显示 4/10 步。

必须知道的两个行为：

  1. 每一步都有防死机保护：默认连续 5 分钟没识别成功，就自动停止当前任务并在日志里写明是哪一步（橙色字）。可以在「截图高级设置」里把这个时间改成 0（关闭）到 120 分钟。所以现在不会出现"一直干等、日志不动"的情况。
  2. 重复操作次数 > 1 时，程序要求目标先消失、再出现才算下一次，防止同一画面被连点。所以别指望"连点同一个按钮 5 次"，那需要 5 个独立任务或者用循环。

8.7 按键触发：按一下键，整组从头重跑

适合"我手动点到某个界面后，让它接手跑固定流程"的场景。

  1. 点顶部 「截图高级设置」
  2. 「按键触发」区选触发按键：ctrl+alt+1、ctrl+alt+2、ctrl+alt+3、ctrl+shift+f9、f8、f9、enter、ctrl+enter
  3. 点 「启用按键触发」（按钮会变成「停用按键触发」，状态显示已启用）

之后在任何地方按下这个键，当前选中的截图组就会立刻从第一个任务重新开始。

  • 每按一次就重跑一次，不会叠加、不会排队
  • 软件自己模拟出来的按键不会误触发（内部已过滤）
  • 建议用组合键：单键（如 enter）在任何输入框里按下都会触发
  • 设置保存在 %APPDATA%\MiaoXiangQiJi\app_settings.json，下次打开自动恢复启用状态

8.8 防死机保护

「截图高级设置」里的「防死机保护」：

  • 单步连续 \_\_ 分钟未识别成功则自动停止当前任务，默认 5 分钟
  • 0 = 关闭该保护（回到"一直等"的老行为）
  • 连续 \_\_ 个分支节点超时未命中则自动停止，默认 10：如果流程一直在"分支等 2 秒 → 超时跳过"，说明页面上已经找不到目标了，连续跳过这么多个分支节点就自动收工（0 = 关闭）。配合"本组循环填大值 + 命中目标"使用，页面上能点的点完了也能干净地停下来
  • 改完点「保存」

触发时会：停止当前截图流程 → 状态栏显示"已超时自动停止：第 N 步「xxx」等待超过 5 分钟"（或"连续 N 个分支节点未命中，已自动停止"）→ 日志橙色记录。

命中目标（点够 N 个就停）：编辑截图任务（或添加条件分支）时有一项「命中目标：\_\_ 次后自动停止整个流程」，默认 0 = 不限制。填 N 以后，这个任务每成功执行一次就记 1 次，累计到 N 次整个截图流程立刻自动停止，日志会显示 🎯 提示。适合点赞、签到这类"每天只算前 N 次"的场景——把本组循环填大（如 999），实际跑多少轮由命中数决定，一次都不会多点。任务列表里会显示 🎯累计命中N次后停止。

8.9 截图组的管理

点顶部 「截图高级设置」，最上面一行是截图组管理：当前组名 + 「新增组」「重命名」「复制组」「删除组」。

  • 一个组 = 一套有先后顺序的认图流程。不同业务放不同组（比如"工资导出""考勤补录"）
  • 「复制组」很适合做变体：复制一份改几张图就是新流程
  • 至少保留一个组，最后一个删不掉
  • 主界面中列的「截图组」下拉框用来切换当前操作的组

8.10 实战：自动点赞（精确点够 20 个就停）

场景：模板市场一页 8 个作品，每个作品有一个小心心——点过的是红色，没点的是灰色。目标：只点亮灰色的心，当前屏幕点完（没有灰心）就往下翻页，一次精确点够 20 个，一个不多（每天只有前 20 个点赞有效）。

准备：截一张灰色小心心的图。⚠️ 只截心形图标本身，千万别把旁边的点赞数字截进去——每个作品的数字都不一样，带数字的图只认得那一个卡片。

任务列表只要 2 条：

#类型关键设置
1条件分支候选图 = 灰色小心心；识别后操作 = 左键单击；匹配阈值 0.85（红心形状相同颜色不同，阈值高才不会误点已赞的红心）；分支等待超时 = 2 秒（2 秒没找到灰心就跳过）；识别后等待 = 0.3 秒；命中目标 = 20；勾选「命中后连续执行」；勾选「点击后校验」
2普通任务截一张页面上固定不变的元素（如顶部的「推荐」标签），识别后操作 = 滚轮下滚，滚动格数 = 3，勾选「未命中时自动加滚」

运行：主界面「本组循环」填一个大数（如 999）（只对当前截图组生效） → 点「▶ 开始按顺序识别并点击」。

原理（为什么要这样改）：

  1. 数成功次数，不数轮数：老办法"循环 20 轮"在已点赞作品多时滚了很多屏也点不够 20 个。现在每点一颗灰心记 1 次，记满 20 次整个流程立刻自动停止（日志出现 🎯 提示），本组循环填多大都不会多点。
  2. 同屏多个可赞作品就连着点：勾选「命中后连续执行」后，分支会一直找灰心、找到一个点一个，直到 2 秒找不到才翻页——不会出现"点一个滚一屏、错过同屏其他作品"的情况。
  3. 滚过头了自动往回补：勾选「未命中时自动加滚」后，如果滚了 3 格还是没看到灰心，下一轮就滚 4 格，再没有就 5 格……每次多滚 1 格；一旦点到灰心，立刻恢复成你设的 3 格。既不会在两屏之间来回卡住，也不会因为步子太小漏看作品。
  4. 被悬浮栏挡住的灰心不空耗：页面底部如果有固定的发布输入栏等悬浮元素，压在下面的灰心"看得见点不着"——勾选「点击后校验」后，点完 1 秒复查，灰心还在原位就说明没点上：这次不计入 20 次命中目标，该位置也不再反复点，等超时后正常翻页；等这颗心滚出遮挡区域后就能正常点上了。

注意事项：

  • 先把「命中目标」设为 1、「本组循环」设为 3 试跑，确认它点的是灰心而不是红心、点满 1 个就停，再改回 20 和 999
  • 阈值低于 0.8 有误点红心（变成取消点赞）的风险；如果还是不放心，可以在点错的那个作品上手动补回来
  • 「命中后连续执行」配合超时使用：超时时间就是"点完这屏后等多久确认没有新的"，一般 2 秒足够
  • 想换一批作品再来 20 个：把页面拖回顶部，再点一次「▶ 开始按顺序识别并点击」即可（设置会记住，命中计数每次启动自动清零）

10. 常见问题

Q：按了「开始执行」鼠标不动，日志也没有新内容？ A：先看「执行队列」是不是空的——空队列点了没反应。然后看日志最后一行，通常在提示原因。

Q：回放时点错位置，整体偏了一段？ A：多半是缩放比例变了。程序按 100%/125%/150% 会自动换算，但录制和回放必须在同一个缩放比例下。换了显示器或改了缩放，建议重录，或者改用认图点击。

Q：快捷键完全没反应？ A：目标程序是管理员权限，而本软件不是。右键 exe → 属性 → 兼容性 → 勾「以管理员身份运行此程序」。

Q：认图任务一直干等，日志不动？ A：截图没匹配上。检查：① 目标界面是否已经打开在前台 ② 截图是不是在本机这个缩放比例下截的 ③ 把匹配阈值从 0.75 降到 0.70 ④ 重新截一张更聚焦目标的图。

Q：认图认错了，点了别的地方？ A：阈值太低或截图特征太弱。把阈值提到 0.85，并截得更有辨识度（带图标、带独特文字的那块）。

Q：想中途取消？ A：脚本执行按 Ctrl+Alt+F12 或「■ 停止」；认图流程点「■ 停止截图识别」。

Q：脚本删了能恢复吗？ A：不能。脚本就是 scripts\ 下的 json 文件，建议定期把整个软件目录压缩备份一份。

Q：能不能拷到别的电脑用？ A：可以。把整个软件文件夹拷走即可——录制脚本、脚本组、混合组、截图组（任务和截图文件）都存在软件文件夹里，跟着一起走。注意两点：① 认图任务依赖截图所在的屏幕特征，换分辨率/缩放后要重新截图；② 定时任务和全局设置存在 %APPDATA%\MiaoXiangQiJi\（不随文件夹走），需要的话把这个文件夹也拷到新电脑的相同位置。

Q：日志里颜色是什么意思？ A：绿=成功完成、红=失败错误、橙=警告/超时/防死机停止、紫=定时任务与按键触发与截图流程、蓝=执行步骤、灰=时间戳。先用颜色扫一眼，再去读具体那几行。

Q：进度条一直不动 / 一下子跳到 100%？ A：脚本回放是按"事件"推进的，一个事件可能就是一个鼠标移动，所以会平滑推进；截图流程按"步"推进，等图期间不动是正常的。当前版本已修正早期"进度瞬间满格"的问题，并会在右侧显示 40% (120/300) 这样的明细。若数字明显对不上，请把日志截图发我。

Q：自己打包时报错，提示 exe 被占用 / 无法覆盖？ A：说明 dist\喵想奇记.exe 还在运行。仓库里的 打包python为软件.bat 已修好：会先自动结束正在运行的旧程序再打包，并在失败时列出常见原因。也可以手动结束「喵想奇记.exe」进程后重试。

Q：按了触发键没反应？ A：① 先确认「截图高级设置」里状态显示"已启用" ② 组合键要同时按下（如 ctrl+alt+1） ③ 单键（如 enter）在部分输入法/游戏里会被拦截，换组合键。

Q：认图流程"循环了 N 轮，但实际没点到想要的次数"？ A：循环数的是轮数，不是成功次数。要"点够 20 个就停"这类效果：给目标分支/任务设置「命中目标 = 20」，再把「本组循环」填大（如 999）——命中记满 20 次自动停，一次不会多点。反过来，如果页面上目标不够 20 个，连续 10 个分支节点超时后也会自动收工（默认值可在「截图高级设置」改）。

Q：同屏有好几个能点赞的作品，它却点一个就翻页，漏掉剩下的？ A：给这个条件分支勾选「命中后连续执行」——命中一个就接着找下一个，直到超时（2 秒）找不到才进入滚动任务。再给滚动任务勾上「未命中时自动加滚」，翻页没翻到目标时每轮多滚 1 格，点到后自动恢复设定格数。详见 8.10。

Q：流程在页面底部某个位置反复点击，但什么都没发生（那里好像被什么挡住了）？ A：页面上有悬浮的输入栏/弹窗压住了目标（"看得见点不着"）。给这个任务/分支勾选「点击后校验」：点击 1 秒后复查，目标没消失就判定为无效——不计入命中目标次数、不再重复点击这个位置，等超时后正常翻页；目标滚出遮挡区域后即可正常点上。日志里会出现"点击后校验：……未生效（不计入命中次数）"的提示。

Q：为什么流程没跑完循环次数就自己停了，日志里有 🎯？ A：这是「命中目标」生效——某任务累计成功执行够了设定的次数，流程自动停止。属于正常行为；不想让它停就把该任务的命中目标改回 0。

Q：日志窗口里的提示看不懂？ A：日志是给排查用的，常见几类： 执行脚本：名字 (×2) 正常开始；队列已暂停，按 Ctrl+Alt+F11 继续 在等人；✅ 所有脚本执行完毕 全部跑完；执行失败：... 后面跟的就是原因。

Q：把软件拷到别的电脑上运行不了，提示"缺少 api-ms-win-core-path-l1-1-0.dll"？ A：那台电脑是 Windows 7。新版 Python（3.9 及以上）打包的程序官方已不支持 Win7，这个 dll 是 Win8/10 系统组件、复制过去也补不齐。两个办法：

  1. （推荐）给那台电脑升级到 Windows 10/11，现在的 exe 直接就能跑
  2. 打一个 Win7 兼容包：在开发电脑上先安装 Python 3.8.10（官方最后一个支持 Win7 的版本，装 32 位版兼容性最好，可与新版 Python 共存；安装时勾选 "Add Python 3.8 to PATH"），然后双击项目里的 「打包python为软件-win7.bat」，它会自动用 3.8 + 固定的旧版依赖（见 requirements-win7.txt）打出 dist\喵想奇记-win7.exe，拷到 Win7 上即可运行。日常给 Win10/11 用的包仍用原来的 打包python为软件.bat，两者互不影响。
