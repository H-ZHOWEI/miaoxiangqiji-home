2026-11-17 v1.8.0
- 手机端新增「自动签到」：在手机 App 里配置打开某 App 后模拟点击/长按/滑动翻页/按文字点击的步骤，可手机手动执行、电脑端下发执行、每日定时执行，支持拟人化随机抖动。
- 电脑端「联动设置 → 本机设置」新增「遥控手机签到」区：读取配对手机上报的签到任务清单，一键让手机执行；执行结果回传到设备页任务通知。
- 配套手机 App 升至 v1.4。

2026-11-17 v1.7.0
- 手机 App 新增远程控制：v1.3 的「远程执行」页加暂停 / 继续 / 停止三个按钮，可遥控当前设备正在跑的任务。暂停/继续对按键脚本和截图识别流程都有效（截图流程冻结在下一步、继续后接着跑）；停止同时中止两类任务并回传「任务已停止」通知。控制指令即使电脑正忙也立即生效，需电脑端 v1.7.0+ 配合。
- 电脑端所有弹窗改为在软件（父窗口）中央打开，不再堆在屏幕左上角；跟随定位的浮层（提示气泡、倒计时、更新进度）保持原位。
- 普通版与 Win7 版同步更新到 v1.7.0。

2026-11-17 v1.6.0
- 联动设置窗口放大：按屏幕自适应（默认不小于 880x620，最大 1180x840），任务组与最近任务通知双栏更宽、列表更高，无需再手动放大即可看全脚本名和通知内容。
- 最近任务通知新增发生时间（月-日 时:分，自动换算本地时区），并标明「控制方 → 被控方」：电脑遥控电脑时显示对方本机名，本机自己跑的标「本机执行」；手机遥控的标「手机」。
- 本机设置页新增「本机名称」，自定义后对方通知里就显示这个名字。
- 安卓手机 App 无需升级即可继续配对使用（老版下发的指令按「手机」显示）。

2026-11-17 v1.5.1
- 修复 Win7 版点「检查更新」报 SSL: CERTIFICATE_VERIFY_FAILED / unable to get local issuer certificate 的问题：Win7 系统根证书库过旧导致 Python 3.8 校验证书失败，更新检查与下载在严格校验失败后自动走兼容通道，下载包仍做 SHA256 完整性校验。
- 若所有通道都失败，错误提示直接给出 GitHub 手动下载地址，不再只显示英文异常。
- 普通版与 Win7 版同步更新到 v1.5.1。

2026-11-17 v1.5.0
- 新增「拟人化输入（随机抖动）」：截图高级设置里可开启，点击位置在目标内小幅随机偏移、每次等待叠加随机快慢、鼠标可分段移动、按下到松开带随机短停顿；四项幅度独立可调、默认全关、随时可恢复精确输入。设置自动保存。
- 仅改变输入表现形式，不读取游戏数据、不注入进程、不改文件；不保证绕过任何反作弊检测，是否违规以目标软件用户协议为准，风险自负。
- 已重新打包普通版与 Win7 版 exe，两者版本与功能完全一致。

2026-11-17 v1.4.0
- 新增电脑之间互相通讯：在联动设置窗里新增「设备」页签，可添加其他电脑的配对码、切换设备、改名/删除；切到某台设备即可查看它的在线状态、任务组清单、最近任务通知，点任务组即可远程让那台电脑执行（对方忙时自动忽略）。与手机遥控共用同一套云端信箱，不额外依赖。
- 电脑端现在既是被控端（本机配对码，允许手机/其他电脑控制、上报任务通知），也是控制端（设备列表里遥控其他电脑）。两台电脑都装 v1.4.0、各自开启联动并互填配对码即可互通。
- 设备数据全部读云端，放在后台线程执行，读取期间界面不卡顿；只能遥控已添加的设备。
