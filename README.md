# 喵想奇记（家用版）

Windows 桌面自动化工具：把重复的鼠标点击、键盘输入、截图识别点击录制成「脚本」，再按需单次执行或定时循环执行。

基于 Python + tkinter 开发，用 PyInstaller 打包为单文件 `喵想奇记.exe`，免安装、双击即用。

> 📘 **新手请先看 [操作说明](操作说明.md)** —— 含界面详解、五分钟上手、认图点击与定时任务配置、常见问题。
> （想直接阅读排版版：下载仓库后打开 `操作说明.html`）

## 主要功能

- **动作录制与回放**：录制鼠标点击、拖动、滚轮与键盘输入，一键回放。
- **截图顺序识别点击**：对屏幕上的一组目标截图依次做模板匹配，识别到就点击，适合操作固定界面。
  - 识别成功后可继续回放按键组合（如 `enter`、`ctrl+s`、`tab, enter`）或直接输入文本（支持中文）。
  - 支持**条件分支**：同时盯多张候选图，哪张先出现就走哪条分支；超时可自动跳过。
  - 支持**鼠标滚轮**动作（上滚/下滚，格数可调），配合分支超时实现"有目标就点、没有就翻页"。
- **按键触发重跑**：设定一个按键 / 组合键（如 `ctrl+alt+1`），按一次就让当前截图组**从第一个任务重跑**；软件自己发出的按键不会误触发。
- **整组循环**：「整组循环 N 次」把任务列表从头到尾跑 N 遍，进度跨轮累计，适合"每轮点一个赞、点完滚一屏"的重复流程。
- **命中目标（点够 N 个就停）**：任务/分支可设"累计成功执行 N 次后自动停止整个流程"，配合整组循环填大值即可"精确点够 20 个赞、一个不多"；另有"连续多个分支超时未命中自动收工"保护。
- **连点 + 自适应翻页**：分支可勾"命中后连续执行"——同屏有多个目标就一个接一个点完，直到超时未命中才翻页；滚动任务可勾"未命中时自动加滚"，翻页没找到目标时每轮多滚 1 格，命中后自动恢复设定格数。
- **点击后校验（防遮挡空耗）**：任务/分支可勾"点击后校验"——点击 1 秒后复查，目标被悬浮输入栏/弹窗挡住没点上时不计入命中目标次数、该位置不再重复点击，等翻页滚出遮挡区后即可正常点上。
- **随时编辑、随时换图**：条件分支支持双击直接编辑（保留任务位置）；「更换截图」按钮只换图片、保留全部设置，页面元素变了不用删任务重建。
- **防死机保护**：任何一步连续 5 分钟没有识别成功，自动停止当前任务并写明卡在哪一步（时间可调，0 = 关闭）。
- **脚本组 / 混合组**：把多个脚本串成流程顺序执行，支持普通脚本、脚本组、截图流程组混排。
- **定时任务**：按指定时间或周期自动触发，触发前有倒计时提醒（默认 3 秒，可调整），倒计时期间可「取消本次」而不影响下一轮。
- **三列全屏界面**：可用脚本 / 截图识别 / 执行队列三列并行，启动自动最大化，窗口拉大不留空白。
- **彩色执行日志**：成功绿、失败红、警告橙、定时与触发紫、步骤蓝，关键操作一眼可见；日志超过 1500 行自动裁剪，长时间挂着也不卡。
- **进度条带明细**：实时显示 `40% (120/300)`，截图流程显示 `4/10 步`，执行完自动满格、停止归零。
- **多分辨率适配**：自动做 DPI 感知与坐标换算，100% / 125% / 150% / 175% 缩放下点击位置一致。
- **文本输入不占用剪贴板**：走 Win32 `SendInput` 直接输入（支持中文），复制文件后不会被替换成路径文字。
- **管理员权限控制**：区分管理员与游客身份，敏感操作需管理员。

## 目录说明

```
automation_app.py      主程序（单文件，约 29 万字符）
scripts/               脚本目录（放你自己录制的 .json 脚本，仓库内为空）
喵想奇记.spec           PyInstaller 打包配置（datas 留空，不把个人脚本打进 exe）
打包python为软件.bat    一键打包脚本（自动关旧进程 → 查依赖 → 打包 → 失败提示）
打包python为软件-win7.bat  Win7 兼容版打包脚本（需先装 Python 3.8.10）
requirements-win7.txt  Win7 兼容版的固定旧版依赖清单
app_icon.ico           程序图标
update_log.txt         更新日志
操作说明.md / .html     使用手册（Markdown 版 / 排版版）
dist/喵想奇记.exe       已打包好的可执行文件（Windows）
```

> 本仓库只包含程序本身，**不含任何录制脚本**。脚本保存在 exe 同级的 `scripts/` 目录，属于使用者个人数据，请自行保管、不要随意分享。

## 直接使用

1. 打开 `dist/喵想奇记.exe`，或在 exe 同级建一个 `scripts` 文件夹存放录制脚本。
2. 若快捷键在本机失灵：右键 exe → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

## 从源码运行

需要 Python 3.9+（Windows），依赖：

```bash
pip install opencv-python numpy pynput Pillow pygetwindow
python automation_app.py
```

## 自行打包

最简单的方式：双击 **`打包python为软件.bat`**。它会依次完成：

1. 自动找可用的 Python（`py` 启动器或 `python`）
2. **自动结束正在运行的旧 `喵想奇记.exe`**（否则 `dist` 里的 exe 被占用会打包失败）
3. 检查 PyInstaller / pynput / Pillow / opencv / numpy，缺了才装
4. 打包，并在失败时列出常见原因

也可以手动打包：

```bash
pip install pyinstaller
pyinstaller 喵想奇记.spec --noconfirm
```

产物在 `dist/喵想奇记.exe`（spec 里 `datas` 为空，不会捆绑任何脚本数据）。

### 打 Win7 兼容包（可选）

`喵想奇记.exe` 用新版 Python 打包，**不支持 Windows 7**（在 Win7 上会提示缺少 `api-ms-win-core-path-l1-1-0.dll`，属系统限制无法绕过）。如需在 Win7 上运行：

1. 安装 [Python 3.8.10](https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe)（官方最后一个支持 Win7 的版本；装 32 位版可在 32/64 位 Win7 上都运行，可与新版 Python 共存，安装时勾选 "Add Python 3.8 to PATH"）
2. 双击 **`打包python为软件-win7.bat`**，它会用 3.8 + 固定旧版依赖（`requirements-win7.txt`）打出 `dist/喵想奇记-win7.exe`

日常给 Win10/11 用的包仍用 `打包python为软件.bat`，两者互不影响。
